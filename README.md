# 🏢 Система учета аренды помещений | Учебный pet-проект, 2026 — Завершен

## 📌 О проекте
Учебный pet-проект по проектированию реляционной базы данных и анализу данных с использованием MS SQL Server / Transact-SQL.

Проект моделирует работу отдела аренды компании ЗАО «Сириус», которая управляет многоэтажным зданием с большим количеством помещений и договоров аренды. Основная задача — создать структуру базы данных, обеспечить целостность данных, реализовать сложные аналитические запросы и автоматизировать бизнес-процессы с помощью программируемых объектов БД.

* **Тип проекта:** Учебный pet-project
* **Роль:** Junior Data / System Analyst
* **СУБД:** MS SQL Server
* **Язык:** T-SQL
* **Статус:** Completed

## 🎯 Цель проекта
Разработать базу данных для автоматизации учета:
* арендаторов (физические и юридические лица);
* помещений (характеристики, этажность, отделка);
* договоров аренды (сроки, стоимость, периодичность);
* бизнес-правил и аналитической отчетности.

## 🗂 Структура базы данных
В проекте реализована реляционная модель из трех основных сущностей с обеспечением ссылочной целостности (Primary Keys, Foreign Keys):
1. **Tenants (Арендаторы)** — физические и юридические лица, их ИНН, банковские реквизиты, контакты.
2. **Premises (Помещения)** — площадь, этаж, наличие телефона, тип отделки.
3. **Contracts (Договоры)** — связующая таблица с историей аренды, суммами, сроками и штрафами.

## 📁 Структура репозитория (Артефакты проекта)

В репозитории представлены следующие SQL-скрипты, демонстрирующие различные уровни владения T-SQL:

### 1. Структура данных и индексы (DDL)
*   **[`create_tables.sql`](./create_tables.sql)** — Создание однотабличной базы данных (`RentOneTable`) и нормализованной многотабличной базы (`Tenants`, `Premises`, `Contracts`). Настройка ограничений целостности: `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `CHECK`, значения по умолчанию (`DEFAULT`). Изменение структуры таблиц (`ALTER TABLE`).
*   **[`indexes.sql`](./indexes.sql)** — Создание некластеризованных индексов B*-дерева (для высокой и низкой кардинальности). Создание фильтрованных (частичных) индексов. Управление ограничениями (`NOCHECK` / `CHECK`).

### 2. Манипуляция данными (DML)
*   **[`inser_data.sql`](./inser_data.sql)** — Заполнение таблиц тестовыми данными (более 50 строк в каждой). Использование системных функций (`GETDATE()`, `USER_NAME()`, `HOST_NAME()`) и операций с датами (`DATEADD`, `DATEDIFF`). Форматирование строк (`UPPER`, `LOWER`, `LEN`, `CHARINDEX`), вычисляемые столбцы и конкатенация.

### 3. Аналитика и выборка данных (Queries)
*   **[`select_queries.sql`](./select_queries.sql)** — Выборка данных с фильтрацией (`WHERE`, `LIKE`, `IN`, `BETWEEN`, `IS NULL`). Агрегатные функции (`SUM`, `AVG`, `MIN`, `MAX`, `COUNT`, `COUNT DISTINCT`) и группировка (`GROUP BY`, `HAVING`). Все виды соединений таблиц: `INNER JOIN`, `LEFT/RIGHT/FULL OUTER JOIN`, `CROSS JOIN`. Операторы множеств: `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`. Вложенные подзапросы. Создание представлений (`VIEW`), синонимов (`SYNONYM`) и последовательностей (`SEQUENCE`).

### 4. Программирование на T-SQL (Programmability)
*   **[`procedures_triggers.sql`](./procedures_triggers.sql)** — Создание хранимых процедур (`CREATE PROC`) и пользовательских функций (`CREATE FUNCTION`). Использование переменных, условных операторов (`IF...ELSE`) и циклов (`WHILE`). Работа с курсорами (явные и неявные, вложенные курсоры). Создание DML-триггеров (`AFTER INSERT, UPDATE, DELETE`) для аудита изменений в таблицах.
