# 🏢 Система учета аренды помещений

## 📌 О проекте

Учебный pet-проект по проектированию реляционной базы данных и анализу данных с использованием **MS SQL Server / Transact-SQL**.

Проект моделирует работу отдела аренды компании ЗАО «Сириус», которая управляет многоэтажным зданием с большим количеством помещений и договоров аренды. Основная задача — создать структуру базы данных, обеспечить целостность данных и реализовать SQL-запросы для получения аналитической информации.

> **Тип проекта:** учебный pet-project  
> **СУБД:** MS SQL Server  
> **Язык:** T-SQL  
> **Статус:** Completed

---

## 🎯 Цель проекта

Разработать базу данных для автоматизации учета:
- арендаторов (физические и юридические лица);
- помещений (характеристики, этажность, отделка);
- договоров аренды (сроки, стоимость, периодичность);
- бизнес-правил и аналитической отчетности.

Дополнительно реализовать SQL-инструменты для анализа данных, контроля их качества и автоматизации бизнес-процессов.

---

## 🏢 Бизнес-контекст

Компания владеет многоэтажным зданием, состоящим примерно из 300 помещений различного назначения. В системе необходимо учитывать:

**Арендаторы:**
- физические и юридические лица;
- контактные и регистрационные данные;
- ИНН, руководитель, банковские реквизиты.

**Помещения:**
- площадь и размеры;
- этаж расположения;
- наличие телефона;
- состояние отделки (обычная, улучшенная, евро).

**Договоры аренды:**
- сроки действия (с сохранением истории);
- стоимость аренды и периодичность оплаты;
- целевое назначение (офис, магазин, склад);
- штрафные санкции.

Один арендатор может арендовать несколько помещений. После окончания срока действия договора информация сохраняется для последующего анализа и ведения истории.
